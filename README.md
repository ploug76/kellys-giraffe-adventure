# Kelly's Giraffe Adventure

Kelly's **first** giraffe game: a free, Mario-style retro platformer starring a tan giraffe with brown patches.
Play: https://ploug76.github.io/kellys-giraffe-adventure/ (installable to the iPhone home screen).

Controls: D-pad, JUMP (red), ACTION (blue). ACTION = tongue (hold UP to lick upward); in the air near a ledge = neck grab; near a golden ring = swing; double-tap ACTION = neck ram (aim with the D-pad).
Keyboard: arrows/WASD, Z/Space jump, X action, C ram, P pause, M mute.

Free — `FORCE_UNLOCKED = true`, no lock.
